Controls · component kit recommendation

relay 0.5.5 · React 19 · Tauri 2 / WebView2 · mockup

Today Relay uses the browser's own checkbox, select and focus ring inside custom-styled forms (Import, Settings), so those controls follow Windows' default look and ignore the theme. The fix is one small set of Relay components on top of a headless library, styled with the same CSS tokens as the rest of the app.

Recommendation: Base UI (@base-ui/react, v1) + Relay tokens in plain CSS. Headless, so the visual language stays Relay's. One tree-shaken package, no CSS-in-JS runtime, and every state is exposed as a data attribute, which plain CSS can target. It covers every control Relay needs (Checkbox, Radio, Switch, Select, Combobox, Menu, Popover, Tooltip, Dialog for the in-app confirm the rules require). React Aria is the runner-up if a11y/i18n depth ever outweighs bundle and API size.

What changes

  • Checkbox, radio and select popup take the theme (native ones stay Windows-blue in dark mode).
  • One focus ring (--ring) everywhere instead of the browser outline.
  • The select popup gets Relay rows, dots and type; native popups cannot be styled.
  • Dialog primitive gives the in-app confirm that CLAUDE.md requires (no confirm()).
