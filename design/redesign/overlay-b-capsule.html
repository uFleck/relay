Overlay · Direction B · Capsule

relay 0.5.5 · design/redesign · mockup, not shipped

A native Windows 11 companion. The tab is a half capsule whose ring fills as today's tasks close. The panel is acrylic over the desktop, with agents shown as avatars whose ring is the lease. Updates arrive as a banner at the top, so the footer only holds sync and the shortcut.

Live · hover the tab, leave to collapse (400 ms grace)

Keeps: every count, claim (holder, elapsed, last progress, lease), next due, sync with retry blink, update state, DND, pin, drag, Ctrl+Alt+R. Changes: a done/today ring on the tab; agent identity by colour avatar (OC, T3, CC); update moves from footer to top banner; needs-you cards are tinted, not bordered.
