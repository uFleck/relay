# Relay

Relay captures notes and tracks the tasks that follow from them.

## Language

**Note**

An entry in the Notebook. A note can contain prose, references, and task directives.

**Task directive**

A note line that starts with an Act, Wait, or Grill marker and can create a task.

**Task**

Work Relay tracks from a task directive. A task retains its original instruction when the note is edited and can be linked to a T3 thread.

**Composer**

The editor for capturing new notes and editing existing ones.

**Rail**

The sidebar that lists the views and holds the update notice and keyboard hints.

**Update notice**

The one-line Rail entry that appears when a newer Relay is available; its tooltip shows the changelog.

**Search**

The floating dialog Ctrl K opens to find notes and tasks.

**Vim mode**

A setting, on by default, that makes the main window keyboard-driven with Normal and Insert modes.

**Normal mode**

The Vim mode state when no text field has focus: keys move, open and act on notes and tasks.

**Insert mode**

The Vim mode state while a text field has focus: keys type text, and Esc returns to Normal mode.
_Avoid_: editing mode

**Dock**

The small capture window the Summon shortcut opens over any app. It only captures: a new note, or lines added to an existing note.
_Avoid_: hover, summon window

**Summon**

Opening the Dock with the global shortcut.

**Append**

Adding Dock text to an existing note instead of creating one. An entry that starts with a reference to a note, or to a task, is added to that note; its task directives create tasks there.
