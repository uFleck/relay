- **What changed** — The hover tool window now owns one Dock session. `Pressed` on `ctrl+alt+r` routes to a main-thread summon that first queries `SHQueryUserNotificationState` (suppressing only exclusive Direct3D full screen), gates on page readiness, treats a second press as dismissal, and captures the foreground HWND plus thread/process identity before showing. Rust resolves the monitor from the saved window's rect centre, then cursor, then primary; reads the physical work area and scale; places hidden with one `SetWindowPos(..., SWP_NOACTIVATE|SWP_NOZORDER|SWP_NOOWNERZORDER)`; clears `WS_EX_NOACTIVATE`, shows with `SW_SHOWNOACTIVATE`, calls `SetForegroundWindow`, moves focus into WebView2, and verifies `GetForegroundWindow() == dock` before emitting `relay://dock-focus`. The fallback ladder is Alt tap via `SendInput`, one `AttachThreadInput` retry (same-thread/invalid targets skipped, detached on every successful attach), then `FlashWindowEx` plus a **Click to focus** hint. A chord held at 250 ms defers the tap off the hotkey stack; the deferred attempt terminates if the foreground is no longer the Dock or the saved window, skips Alt while modifiers remain, and still flashes/hints if nothing activated. Esc, submit and a second press snapshot foreground before hiding and restore the saved window only when the Dock still owned focus and the window is valid with matching identity; native blur hides and discards the target. Stale session ids cannot resize or dismiss; no state lock is held across Win32 calls. The page registers `dock_ready` with a measured compact height, observes the intrinsic content root with `ResizeObserver`, adds the settled picker box for the three layout states, grows before revealing the picker, shrinks after its transition (immediately under reduced motion), deduplicates observations, and keeps the draft mounted across Esc/blur. A native scale-factor change re-reads work area and scale, re-applies the anchored rectangle, and asks the page to remeasure. `Win32_UI_Shell` and `Win32_System_Threading` were added to the Windows features. Debug diagnostics record activation step, verified foreground, shell style, work area, scale and applied rectangle, with no Note text or window titles.
