## UI states

- **Settings → GitHub:** dot + "Connected" (green) / "No token"; poller or command error in red below; password field `ghp_…`; Save shows a spinner and "Checking token…" while Rust validates with one real call; Clear when configured; "Sync pull requests now" disabled while running, then "Updated N pull requests" or the error in red; note on optional token, anonymous rate limit and Windows Credential Manager. Follows `github://status`.
- **Projects:** each project row shows the path, "Repository linked" (path unknown, see risks) or "No repo"; branch, short head, dirty dot, head subject when git state loads; refresh button; "Choose folder" (plugin-dialog `open({ directory: true })`) and "Clear". A failing `projectGitState` (not a repo) or `projectSetRepo` shows inline in red.
- **Task sheet → Context:** git line + refresh, or the git error inline; one row per `pr` link with title (or short URL), state chip (open/draft/merged/closed), checks chip, review chip, and an external-link button through the existing `openExternal` (opener plugin) passed in as `onOpen`. Hidden when there is no repo, no git error and no PR link.

## Known risks

- **Contract gap:** the brief says the snapshot carries `Project.repoPath` and link `metadataJson`; the wire view in `crates/relay-core/src/view.rs` (`Project { id, name, colorVar }`, `TaskLink { kind, label, state, url }`) has neither. The UI types them optional and degrades: a linked project shows "Repository linked" (path known only for the session after Choose folder), and every PR reads `checks none` / `review none`. Adding both fields to `view.rs` lights the UI up with no front-end change.
- No live PR to poll: the sync button, chips with real metadata and `github://status` updates were not exercised against GitHub.
- Folder picker not exercised: `open({ directory: true })` was type-checked only; the app was not started.
- Metadata may be empty for old links: links the poller has not reached read as `none`.
- `ProjectRepo` reloads git state per project on every window focus and `relay://change`; fine for a handful of projects, worth batching if the list grows.
