- **What changed** — Core now classifies provider failures into a typed `ProviderFailure` that distinguishes sign-in, configuration, rate limit, permission, not found and transport, keeping tokens and raw provider messages in Rust. `GithubClient` gained repo-scoped text search with a registered-repo allowlist and bounded fan-out, a direct issue/PR read whose pull marker classifies a bare `#142`, and a one-request lightweight PR summary with merged/draft state. `ClickUpClient` gained `GET /task/{native_id}` in one request, assignee ids and provider update time. A new `v2::live` module owns eligibility (two characters), query shapes (`#142`, `#142 owner/repo`, `owner/repo#n`, `CU-…`), credential-independent typing and conversion to the shared `V2PickerRow`; public GitHub reads and stored-token → `gh` → public precedence are retained, and ClickUp title matching stays local. A new `0004` migration adds `ref_recovery`, keyed by canonical identity so one link shared by both windows and many Notes has one schedule. `V2Store` persists picked snapshots into `ref_targets` without a Note/Task/ledger row, atomically ensures an unreadable or stale link gets one recovery row at Note/Task save, exposes due and paused reads, unpauses only on a credential-digest change, and applies worker decisions with an `updated_at` guard that discards an older completion. Core recovery owns the 30s/2m/10m/30m-capped backoff, an optional provider rate-limit deadline, pause reasons and outcome policy. The Tauri adapter resolves v2 credentials, exposes `v2_reference_search`, `v2_reference_exact` and `v2_reference_pick`, emits `relay://reference-change` on a picked or recovered snapshot, and runs the worker from startup against the v2 database; it listens for provider-status changes to re-evaluate paused work. The shared picker now shows local results from the first keystroke, starts a bounded live query after two characters and about 250 ms, shows a quiet provider row that becomes a slower status after about three seconds, surfaces known outages/missing credentials immediately, ignores responses whose query changed, refreshes duplicates in place, appends new rows within their group and keeps the highlighted key, and starts a deduplicated exact read when a known URL is pasted into an open draft.
