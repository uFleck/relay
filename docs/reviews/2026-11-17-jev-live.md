# JEV live spike: real System One answers

**Status:** complete.
**Agent / model:** Opus 5.5 (orchestrator), with the key from `TYPESAFE_API_KEY`.
**Endpoint:** `POST https://api.typesafe.ai/v1/systemone`, bearer key from the environment (never printed).

## Why

The client and routing in `crates/relay-core/src/jev.rs` were tested against a local mock. This spike checks
the real API accepts the exact question shapes Relay sends, and that the answers route the way PLAN 3.2 says.

## Stage A

State: two messages ("can you make the settings panel show the MCP status?", "sure, I'll do it today").

| Question | Type | Answer |
| --- | --- | --- |
| `worth_reviewing` | Noul | **0.96** |
| `conversation_state` | Choice | `waiting_on_me` (0.41) |

Model `jev-1.14.0`, usage 389 in / 72 out. `worth_reviewing 0.96 > 0.60` → stage B runs.

## Stage B

State: a two-message transcript about hiding the raw token and running the update check on launch, plus three
candidate tasks (`Add MCP setup to Settings` In Progress, `Auto-update on launch` Todo, `Hover window expand`
In Review).

| Question | Type | Answer |
| --- | --- | --- |
| `affects_existing` | Noul | **0.75** |
| `task` | Choice | **`multiple`** (0.80) |
| `change_kind` | Choice | `new_task` (0.63) |
| `is_new_task` | Noul | **0.71** |
| `conversation_complete` | Noul | 0.47 |
| `urgency` | Score (3 levels) | **1.32** (0.54 at "this week", 0.39 at "today-blocking") |
| `needs_human` | Noul | 0.60 |
| `project` | Choice | `unsure` (0.69) |

Model `jev-1.14.0`, usage 826 in / 268 out.

## What the routing does with this

Following `route()` and the threshold table:

- `affects_existing 0.75 > 0.70`, but `task = multiple` → **review queue**, never auto-apply. This is the
  "one change per task, the reviewer splits" path.
- `is_new_task 0.71 < 0.80` → no new task.
- `needs_human 0.60` is **not** `> 0.60`, so it does not by itself force review; the `multiple` task does.
- The conversation is not complete (0.47), so an immediate job would be a change job, not a close job.

That is the documented behaviour, from real answers, not a fixture. It also confirms the two-stage cost is
reasonable: 1.2k tokens for both calls on a short episode.

## Caveats

- One sample does not calibrate thresholds. Shadow mode over the 14-day backfill is still the plan.
- The key is read from `TYPESAFE_API_KEY`; the app does not read the environment yet (it will take the key
  from Credential Manager / the setup sheet).
